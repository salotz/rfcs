As an editor of RFCs you are responsible for checking the work of the author.

## Check Links

All links should be checked that they are valid.

## Check Metadata

Metadata should be valid and complete.

## Spelling and Grammar

Spelling and grammar should be fixed where obvious. Larger changes
should request input from the author.

## Index

There should be an index entry given in the top-level `README.md` for
each new RFC.
