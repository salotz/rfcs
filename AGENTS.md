This is a repository with plain-text content that describes
mini-standards called RFCs (request for comments).

The index of standards with metadata lives in the [README](README.md),
treat this like the table of contents.

The actual content for each RFC is in the [rfcs](rfcs/) folder.

Agents should perform requested work processes which are documented in
[contributing](contributing/).

As an editor or agent making changes, follow the checklist in
[contributing/editing.md](contributing/editing.md) (link validation,
metadata completeness, spelling/grammar, and index updates).
